# 2번 발표 전체 아웃라인

**제목**: "AI로 PT를 쉽게 만들 수 있을까?"
**부제**: "를 AI에게 시켜본 뒤 그 대답을 AI에게 써달라 맡기고 그걸 가져다가 또 PT를 만들어 달라하기"

**총 시간**: 25-33분
**톤**: 캐주얼하고 솔직한 + 영감을 주는 스토리텔링
**청중**: 회사 동료 전원 (개발자 + 비개발자)

## 🎯 전체 메시지

**과거 (Part 1)**: "홀덤 발표 만들면서 자연스럽게 패턴 발견했다"

## Part 1: "홀덤 발표 만들면서 패턴 발견"

**시간**: 12-15분
**시간축**: 과거 (첫 번째 프로젝트)

### 구조

#### 1. 오프닝: 워케이션 스토리 (3-4분)
- **슬라이드**: 워케이션 사진, 동기 플로우차트
- **내용**:
  - 배경: 워케이션 → 홀덤 하고 싶음
  - 문제: "도박 주선자" 오해
  - 해결: 홀덤의 멋짐 알리는 발표
  - 제약: 업무시간 사용 불가
  - 메타 솔루션: AI로 만들기 + 과정 보여주기
  - 초기 기대: "딸깍?"

#### 2. 헤프닝 4가지 + 패턴 발견 (8-10분)

각 헤프닝당 2-3분

**헤프닝 1: "개구리" 사건**
- 시도: "홀덤 발표 만들어줘"
- 결과: 중앙에 큰 텍스트 (PPT 스타일)
- 피드백: "이거 진짜 개구리다"
- **발견한 패턴**: 계층적 접근 (패턴 1)
  ```
  책 목차 (논리)
    ↓
  스크립트 (말)
    ↓
  슬라이드 (시각)
  ```
- **슬라이드**: Before/After 비교, 계층 다이어그램

**헤프닝 2: 컴포넌트 착각**
- 상황: 52장 카드 필요
- 처음: 완성된 슬라이드 이미지
- 피드백: "presentation page를 그리는구나..."
- **발견한 패턴**: 컴포넌트 기반 설계 (패턴 5)
  - 레고 블록처럼
  - 재사용 가능한 작은 요소들
- **슬라이드**: 완성품 vs 컴포넌트 비교, 25개 요소 갤러리

**헤프닝 3: Fragment 디버깅 30분**
- 문제: 애니메이션 이상 동작
- 시행착오: WebSearch, Python, Chrome MCP
- **발견한 패턴**: 도구 조합 활용 (패턴 8)
  - 자동 검증 + 수동 검증
  - 여러 도구 조합
- **슬라이드**: 디버깅 타임라인, 도구 아이콘

**헤프닝 4: 세션 관리**
- 문제: 컨텍스트 부족, 여러 작업 동시
- **발견한 패턴**: 파일 기반 상태 관리 (패턴 6, 10)
  - "파일은 영원, 대화는 일시적"
  - SESSION-LOCK.md
- **슬라이드**: 세션 다이어그램, Lock 시스템

#### 3. 결과: 10가지 패턴 정리 (1-2분)
- methodology.md 1099 lines
- 각 헤프닝에서 배운 것들
- **슬라이드**: 패턴 10개 목록

### 리소스

- `debugging-reveal-js-fragments.md` (케이스 스터디)
- `development-log/CLAUDE.md` (작업 원칙)

### 주요 슬라이드
1. 워케이션 타임라인
2. 동기 플로우차트
3. "개구리" Before/After
4. 계층적 접근 다이어그램

✅ 패턴 5 (컴포넌트):
