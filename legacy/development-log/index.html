🤖 Claude Code로 만드는 홀덤 프레젠테이션

AI 페어 프로그래밍의 실제 사례

⚡ Claude Code × Human Collaboration

📋 프로젝트 개요

이 프로젝트는 Claude Code를 활용하여 홀덤(텍사스 홀덤)을 소개하는 인터랙티브 프레젠테이션을 제작하는 과정을 담고 있습니다.

단순히 프레젠테이션을 만드는 것을 넘어, AI와 함께 협업하는 방식을 동료들에게 보여주는 메타적인 목적도 가지고 있습니다.

🎨 프론트엔드

HTML5, CSS3, Reveal.js

🤖 AI 도구

Claude Code (Sonnet 4.5)

📝 콘텐츠

홀덤 소개, 전략, 마인드셋

🎯 목표

흥미롭고 교육적인 프레젠테이션

⏱️ 개발 과정 타임라인

1단계: 프로젝트 기획 및 요구사항 정의

사용자가 프로젝트의 목적을 설명하고, Claude Code가 질문을 통해 요구사항을 명확히 했습니다.

👤 사용자:

"홀덤 소개 PPT를 만들고 싶어. 대상은 완전 초보자이고, 부정적 인식을 전환하고 싶어."

🤖 Claude Code:

"프레젠테이션 스타일, 포함할 내용, 디자인 선호도에 대해 여쭤보겠습니다..."

핵심 결정사항:

  • 대상: 홀덤에 부정적 인식을 가진 완전 초보자
  • 목표: 게임의 깊이와 마인드 스포츠적 가치 전달
  • 형식: reveal.js 기반 단일 페이지 슬라이드
  • 스타일: 모던하고 미니멀한 디자인
  • 메타 목적: Claude Code 시연

2단계: 프로젝트 구조 설계

Claude Code가 프로젝트 전체 구조를 설계하고 계획을 제시했습니다.

/ ├── index.html # 메인 프레젠테이션 ├── script.md # 발표 스크립트 ├── css/style.css # 커스텀 스타일 ├── images/ # 이미지 리소스 ├── videos/ # 영상 리소스 ├── development-log/ # 개발 과정 문서 │ ├── index.html │ ├── chat-history.md │ └── screenshots/ └── README.md # 프로젝트 설명

이 구조는 프레젠테이션 본체뿐만 아니라 개발 과정을 문서화하는 부분도 포함합니다.

3단계: 콘텐츠 기획

슬라이드 구성을 함께 논의하고 스토리라인을 만들었습니다.

슬라이드 구성 (19개 슬라이드):

  1. 타이틀: "홀덤: 생각보다 깊은 마인드 스포츠"
  2. 도발적인 질문 (통념 제시)
  3. 통념 깨기 (통계로 반박)
  4. 홀덤이란?
  5. 왜 도박이 아닌가?
  6. 수학적 게임 (팟 오즈, 기댓값)
  7. GTO (게임 이론 최적화)
  8. 게임 진행 방식
  9. 핸드 랭킹 (1-5위)
  10. 핸드 랭킹 (6-10위)
  11. 전략의 깊이
  12. 실전 예시 (의사결정)
  13. 마인드 스포츠로서의 가치
  14. 인생에 주는 교훈
  15. 프로의 세계
  16. 피드백이 가능한 게임
  17. 시작하기
  18. 마무리 메시지
  19. Q&A

4단계: HTML 구조 생성

reveal.js를 활용한 프레젠테이션 HTML 파일을 작성했습니다.

주요 기능:

  • CDN을 통한 reveal.js 로드 (빠른 프로토타이핑)
  • 슬라이드별 애니메이션 효과 (fragment)
  • 그라데이션 배경 활용
  • 발표자 노트 지원 (RevealNotes 플러그인)
  • 줌 기능 (RevealZoom 플러그인)

5단계: CSS 스타일링

모던하고 미니멀한 디자인을 위한 커스텀 CSS를 작성했습니다.

디자인 특징:

  • Google Fonts (Noto Sans KR, Montserrat) 사용
  • CSS 변수로 색상 테마 관리
  • 그라데이션 텍스트 효과
  • 호버 애니메이션
  • 반응형 그리드 레이아웃
  • 카드 형태의 정보 배치

6단계: 발표 스크립트 작성 (진행 중)

각 슬라이드에 대한 상세한 발표 스크립트를 작성 중입니다.

예상 질문과 답변, 타이밍 가이드, 강조 포인트 등을 포함한 완전한 발표 가이드를 제공할 예정입니다.

6.5단계: 재사용 가능한 Diagram Elements 생성

프레젠테이션에 필요한 시각 자료를 위해 25개의 재사용 가능한 SVG 컴포넌트를 생성했습니다.

👤 사용자:

"음 다이어그램에 필요한 요소를 뽑아주는 줄 알았는데 그냥 presentation page 1개를 그려주는구나. 그건 여기 역할이 아니야."

🤖 Claude Code:

"아, 완성된 슬라이드가 아니라 레고 블록처럼 조립 가능한 작은 요소들이 필요하시군요. 카테고리별로 재사용 가능한 SVG 컴포넌트를 만들겠습니다."

핵심 인사이트: 컴포넌트 기반 설계

  • ❌ 잘못된 접근: 완성된 슬라이드 이미지 (한 번 쓰고 버림)
  • ✅ 올바른 접근: 조립 가능한 작은 요소들 (여러 곳에서 재사용)

생성된 컴포넌트 (25개):

  • 게임 구성 요소 (7개): chip-stack, pot-icon, player-seat, card-placeholder, community-card-area, betting-arrow, dealer-button
  • 액션 뱃지 (5개): FOLD, CALL, RAISE, thinking-bubble, winner-badge
  • 인디케이터 (6개): percentage-badge, ev-indicator, odds-ratio, checkmark, x-mark, warning
  • 비교 템플릿 (3개): vs-divider, comparison-table, pro-con-boxes
  • 전략 시각화 (4개): hand-strength-bar, range-grid, position-diagram, gto-exploit-icon

또한 DIAGRAM-ELEMENTS.md (6000+ 라인)를 작성하여 각 요소의 사용법, HTML 예시, 조합 패턴을 상세히 문서화했습니다.

작업 방식:

  • 카테고리별 폴더 구조 설계
  • 병렬 파일 생성 (독립적 → Write 도구로 동시에 여러 개)
  • 일관된 디자인 패턴 (컬러 스킴, drop shadow, 크기 통일)
  • 포괄적인 사용 가이드 작성

7단계: 개발 과정 문서화 (현재)

Claude Code와의 협업 과정을 문서화하여 동료들에게 AI 페어 프로그래밍의 가능성을 보여줍니다.

8단계: 리소스 추가 및 인터랙티브 요소 (예정)

이미지, 영상 등의 멀티미디어 리소스와 확률 계산기, 핸드 시뮬레이션 같은 인터랙티브 요소를 추가할 예정입니다.

🤖 Claude Code 활용 방법

1. 대화형 요구사항 수집

Claude Code는 단순히 코드를 생성하는 것이 아니라, 질문을 통해 프로젝트의 요구사항을 명확히 파악합니다.

"프레젠테이션의 대상 청중은 누구인가요?", "어떤 스타일을 선호하시나요?", "어떤 내용을 포함하고 싶으신가요?"

이러한 질문들을 통해 프로젝트의 방향성을 함께 정립했습니다.

2. 구조화된 계획 수립

요구사항을 바탕으로 Claude Code가 전체 프로젝트 구조를 설계하고 단계별 계획을 제시합니다.

  • 폴더 구조 설계
  • 파일 명명 규칙
  • 기술 스택 선정
  • 작업 순서 정리

3. 빠른 프로토타이핑

Claude Code는 몇 분 만에 작동하는 프로토타입을 생성할 수 있습니다.

  • 완전한 HTML 구조 생성
  • 즉시 사용 가능한 CSS 스타일
  • 실제 콘텐츠가 포함된 슬라이드

4. 일관성 있는 코드 작성

전체 프로젝트의 맥락을 이해하고 일관된 코딩 스타일과 네이밍 컨벤션을 유지합니다.

5. 문서화

코드뿐만 아니라 발표 스크립트, README, 개발 과정 문서 등 프로젝트에 필요한 모든 문서를 생성합니다.

협업의 본질

Claude Code는 대체가 아니라 증강입니다.

  • 인간이 방향성과 창의적 결정을 내립니다
  • AI가 실행과 구현을 담당합니다
  • 함께 더 나은 결과물을 만듭니다

📖 이 프로젝트에서 배운 점

1. 명확한 커뮤니케이션의 중요성

AI와의 협업에서도 사람과의 협업과 마찬가지로 명확한 요구사항 전달이 중요합니다.

2. 반복적 개선

한 번에 완벽한 결과를 기대하기보다, 피드백을 통해 점진적으로 개선하는 것이 효과적입니다.

3. 도구의 한계 이해

Claude Code가 강력하지만, 창의적 방향성과 최종 결정은 여전히 인간의 몫입니다.

4. 문서화의 가치

개발 과정을 문서화하는 것이 팀과의 지식 공유에 얼마나 중요한지 깨달았습니다.

5. 세션 연속성 관리

긴 프로젝트에서는 Claude Code의 컨텍스트(메모리)가 부족해질 수 있습니다.

이 프로젝트의 경우:

세션 1: YouTube 스크린샷, 카드 생성, hand rankings 차트, diagram elements 시작 → 약 180K 토큰 사용
세션 2 (현재): Claude가 자동으로 대화를 요약하여 새 세션 시작 → Diagram elements 완료, development log 작성

핵심 교훈: "파일은 영원하고, 대화는 일시적이다"

  • 중요한 결정은 파일에 기록 (CLAUDE.md, outline.md)
  • Claude가 세션이 바뀌어도 파일을 읽고 맥락 이해
  • 자동 요약으로 핵심만 남겨 더 집중된 작업 가능
