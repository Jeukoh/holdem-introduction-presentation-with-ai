## 슬라이드 2.1.3: 홀덤 소개

**목표**: 텍사스 홀덤의 핵심 규칙 한 줄 요약

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│                      Texas Hold'em                              │
│                                                                 │
│                                                                 │
│                                                                 │
│                      7장 중 5장                                  │
│                                                                 │
│                   으로 족보를 만들어 대결                         │
│                                                                 │
│                                                                 │
│         ┌──┐┌──┐           ┌──┐┌──┐┌──┐┌──┐┌──┐                │
│         │??││??│     +     │  ││  ││  ││  ││  │                │
│         └──┘└──┘           └──┘└──┘└──┘└──┘└──┘                │
│          내 패              커뮤니티 카드                        │
│         (2장)                 (5장)                             │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

| 항목 | 내용 |
|-----|------|
| 에셋 | 카드 뒷면 이미지, 빈 카드 플레이스홀더 |
| 애니메이션 | fragment로 "내 패" → "커뮤니티 카드" 순서 |

**발표자 노트**:
> 그래서 홀덤은 뭐냐.
> 7장 카드 중에서 가장 좋은 5장을 골라서 대결하는 게임이에요.
