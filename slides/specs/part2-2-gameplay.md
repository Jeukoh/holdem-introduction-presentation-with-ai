## 1판: UTG - 관찰자 모드 (흐름 학습)

### 시나리오 설정
- **내 포지션**: UTG (가장 불리)
- **내 카드**: 72o (최악의 핸드)
- **목적**: 폴드 후 쇼다운까지 관전하며 게임 흐름 학습

### Steps

| Step | Phase | 내용 | 시각화 |
|------|-------|------|--------|
| 0 | setup | 테이블 + 포지션 표시 | 6인 테이블 |
| 1 | blinds | SB $1, BB $2 | 칩 애니메이션 |
| 2 | deal | 카드 딜링 | 모두 뒷면, 내 카드 공개 (72o) |
| 3 | preflop | **내 차례! 뭐지?** | UTG 하이라이트, "?" 표시 |
| 4 | preflop | 폴드 | 카드 버림, "일단 죽자..." |
| 5 | preflop | HJ 콜 | $2 칩 |
| 6 | preflop | CO 레이즈 $6 | $6 칩, "RAISE" |
| 7 | preflop | BTN 콜 | $6 칩 |
| 8 | preflop | SB 폴드 | 카드 버림 |
| 9 | preflop | BB 콜 | $4 추가 |
| 10 | preflop | HJ 콜 | $4 추가 |
| 11 | flop | 플랍 공개 | K♠ 7♥ 2♦ |
| 12 | flop | BB 체크 | "CHECK" |
| 13 | flop | HJ 체크 | "CHECK" |
| 14 | flop | CO 벳 $10 | 칩 |
| 15 | flop | BTN 콜 | 칩 |
| 16 | flop | BB 폴드 | 카드 버림 |
| 17 | flop | HJ 폴드 | 카드 버림 |
| 18 | turn | 턴 공개 | J♣ |
| 19 | turn | CO 벳 $20 | 칩 |
| 20 | turn | BTN 콜 | 칩 |
| 21 | river | 리버 공개 | 9♠ |
| 22 | river | CO 체크 | "CHECK" |
| 23 | river | BTN 벳 $30 | 칩 |
| 24 | river | CO 콜 | 칩 |
| 25 | showdown | 쇼다운! | 카드 오픈 |

### 핸드 배정
- **UTG (나)**: 7♦ 2♣ (폴드)
- **HJ**: J♦ T♦ (폴드)
- **CO**: A♠ K♦ (탑페어)
- **BTN**: K♣ J♥ (투페어) ← 승자
- **SB**: 9♥ 4♣ (폴드)
- **BB**: Q♠ 8♠ (폴드)

### 발표자 노트
> (Step 3) 카드 받자마자 내 차례! UTG니까요.
> (Step 4) 72o... 최악의 핸드. 폴드!
> (Step 6) CO가 레이즈 - 강한 핸드 신호
> (Step 11) 플랍! 3장 공개. 이제 베팅 다시 시작
> (Step 18) 턴! 판이 커지네요
> (Step 21) 리버! 마지막 카드
> (Step 25) 쇼다운! 카드 오픈

## 필요한 모달 컴포넌트

```jsx

```

**디자인**:
```
┌─────────────────────────────────────┐
│  📍 포지션 용어                      │
│  ─────────────────────────────────  │
│  BTN (Button)   = 딜러. 가장 유리   │
│  SB (Small Blind) = 강제 $1        │
│  BB (Big Blind)   = 강제 $2        │
│  UTG (Under The Gun) = 가장 불리   │
│  HJ (Hijack)    = 중간             │
│  CO (Cutoff)    = BTN 직전         │
│  ─────────────────────────────────  │
│  💡 매 판마다 시계방향으로 이동!     │
└─────────────────────────────────────┘
```

**스타일**:
- 반투명 검은 배경
- 흰색 텍스트
- 테이블 중앙에 오버레이
